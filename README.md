# Durrani Estates Admin

Real estate CRM admin dashboard for **Durrani Estates** — leads, assignments, bookings, people & sales, and operations.

## Scripts

```bash
npm install
npm run dev
```

App runs via Vite (default preview port `4200` for `npm run preview`).

## Stack

React 19 · Vite · React Router · Tailwind CSS v4 · shadcn/ui · TanStack Query/Table/Form
